Data types

Categorical a labeled value - string
Pizza example - what topping do you like, restaurant type

Numeric - numbers, int/float
Pizza example - how many slices, prices

Ordinal - where order matters, a rating?
Pizza example - how spicy is it, restaurant rating?

Levels of measurement
Nominal - a label, similar to categorical - region, product type

Ordinal - Ranked order - satisfaction level, priority
The value between rankings might not be constant

Interval - equal spacing between values, but zero doesnt mean none
temperature, time of day, years
the amount of value between times is consistant
0 degrees doesnt mean no temperature at all

Ratio - "regular numbers" with true zero
Revenue, time spent, file size
zero revenue means no money

Data science terms
Population vs samples
population: the entire group
sample: a subset of the population that we actually collect data from

Statistics vs parameters
Parameter a value that descrives a characteristic of an entire population
statistic a value calculated from a sample

Parameter from population
Statistic from sample
